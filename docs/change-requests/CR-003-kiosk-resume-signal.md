# CR-003 (대상: 헤드 -> survey-service) 위험 정지가 풀린 것을 키오스크가 알 방법

작성: kiosk-frontend. 문제(확인한 것): 위험 정지가 나면 키오스크는 "직원이 곧 도와드립니다" 화면에서 기다린다. 직원이 개입(`RESUME`)을 보내면 안내 문장(`FrontendInput.response_text`)은 **직원 콘솔의 응답**으로만 돌아가고, 키오스크는 풀렸는지 알 수 없다. 계약에는 키오스크가 상태를 조회하거나 구독하는 호출이 없다.

현재 구현(임시): 키오스크는 대기 화면에서 환자가 다시 말하면 그 발화를 보낸다. 정지 중이면 서버가 409를 주고 키오스크는 대기 화면에 머문다. 풀렸다면 정상 응답을 받는다. 즉 환자가 직접 다시 시도해 보는 방식이다. 이때 `RESUME` 때 이어서 할 안내 문장은 키오스크에 보이지 않는다(확인하지 못함: 실제 서버의 동작).

제안(택일, 헤드 판단):
- A. `GET /v1/sessions/{session_id}/state` -> `{ "paused": bool, "resume_text": string|null }` (키오스크 역할, 폴링).
- B. 정지 중 세션의 다음 턴 응답에 `RESUME` 안내 문장을 한 번 실어 준다(호출 추가 없음, 서버 규칙만).
- C. 키오스크용 SSE.
이 영역은 A 또는 B를 선호한다(키오스크 쪽 변경이 가장 작다).
