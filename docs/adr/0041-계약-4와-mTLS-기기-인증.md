# ADR 0041: 계약 4.0.0의 mTLS 기기 인증

상태: 채택 (2026-11-07).

폐기 예고된 device_token과 #device 설정을 제거한다. 인증서·개인키는 브라우저/운영체제가 관리하고 앱은 기기 자격증명이나 게이트웨이 신원 헤더를 전송하지 않는다. 폐기된 필드를 포함한 설정은 정본의 닫힌 스키마로 거부한다.

세션 시작은 PublicApiRequests.SessionStartBody를 송신 전 검증하고 서버 발급 session_id를 사용한다. 문진 내부 FrontendMessage와 HTTP 시작 본문은 구분한다. 생성기는 고정 계약과 문진 스키마의 전이 참조를 오프라인 등록하며 검증 코드·규칙 버전을 함께 생성한다. TypeScript로 표현할 수 없는 not 조건은 타입 투영에서만 제외하고 런타임 검증에는 유지한다.

건강 확인은 선언된 바인드 주소와 포트를 따르며 IPv6 authority에 괄호를 붙인다. 개인정보 콘솔/모의 접근 로그 비기록, 서버 ID, 송신 헤더 부재, 폐기 필드 거부를 시험한다. 전체 프로젝트 E2E는 이 영역에서 실행하지 않는다.
