# 표준 형식 검증을 독립 생성물에 포함한다

## 상태
채택.

## 맥락
Ajv의 format 확장을 연결하지 않아 date-time 같은 계약 조건이 경고만 내고 무시됐다.
생성된 검증기는 npm 설치 없이도 빌드 진입점에서 실행되어야 한다.

## 결정
고정된 ajv-formats를 생성 시 연결한다. Ajv standalone 코드와 형식·문자 길이 도우미를 esbuild로 함께 묶는다.
날짜 비교나 Unicode 문자 수를 손으로 재구현하지 않는다.

## 왜
Ajv의 공식 [형식 검증](https://ajv.js.org/guide/formats) 및 [독립 코드 생성](https://ajv.js.org/standalone.html) 방식을 따른다.
생성 시 사용한 라이브러리 코드가 산출물에 포함되어 실행 환경의 node_modules 구조를 몰라도 된다.

## 검토한 대안
format 무시는 계약을 온전히 구현하지 못한다. 수기 날짜 검사와 라이브러리 함수 복사는 정의가 어긋날 수 있다.
실행 시 Ajv 컴파일은 기존 CSP 및 독립 실행 요구와 맞지 않는다.

## 결과
생성물 크기가 늘어난다. 생성 최신성·타입 검사·유효하지 않은 달력 날짜의 거부를 시험한다.
스키마 원본은 고정 태그에서 읽으며 생성물은 직접 수정하지 않는다.

## 되돌리는 조건
동등한 표준 검증과 독립 실행을 제공하는 생성기로 이전하면 새 ADR로 대체한다.
