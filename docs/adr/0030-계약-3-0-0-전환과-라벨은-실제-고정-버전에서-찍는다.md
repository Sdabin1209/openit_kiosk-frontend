# ADR 0030: 계약 3.0.0 전환, 이미지 설정이 정본, 라벨은 실제 고정 버전에서 찍는다

## 상태
**survey-schema 라벨 부분은 ADR 0031로 고쳤다(이 이미지는 문진 스키마를 담지 않아 n/a).** 채택됨 (2026-10-30, 계약 v3.0.0, OPEN_GAPS U50). ADR 0026(빌드 진입점)의 "요청 버전을 빌드 인자로 넘긴다"와 "turn_engine은 받아도 무시한다", ADR 0029의 StaticImageInterface 비교 절을 대체한다.

## 맥락
계약 3.0.0은 깨지는 변경을 모았다. 이 영역에 닿는 것: (1) `BuildImageRequest.versions.turn_engine`과 라벨 `io.openit.turn-engine` 제거, (2) `StaticImageInterface` 제거(포트·사용자·환경 변수는 OCI 이미지 설정이 표준이고 경로는 `Exposure` 라벨이 담는다), (3) `SetupEnvReport`는 status ok일 때 environment 필수(이 영역은 처음부터 항상 낸다), (4) `PIPELINE_SCHEMA_VERSION` "3.0". U50: 라벨이 요청 값이 아니라 실제로 쓴 버전이어야 한다.

## 결정
- 계약 고정을 v3.0.0으로 올렸다(Dockerfile ARG, 생성 검증기 두 개, 모의 서버 `pipeline_schema_version` "3.0", 시험의 기대값).
- `StaticImageInterface` 선언서 `docs/image-interface.json`과 그 시험을 지웠다. 포트·사용자·환경 변수의 정본은 `Dockerfile`의 `EXPOSE`·`USER`·`ENV`이고 시험(`test/image-contract.test.ts`)이 값(8080, root 아님, `PORT`·`STATIC_DIR` 기본값)을 확인한다. 경로 노출은 `deploy-exposure.json`(Exposure 라벨, ADR 0029)과 실제 이미지 시험이 확인한다.
- 이 영역에서 turn-engine 표지·라벨·의존이 없다. `git grep`에 남는 것은 이 변경을 설명하는 ADR·시험·상태 기록뿐이다.
- U50: `scripts/build-image.sh`는 라벨 `io.openit.contracts.boundary`·`io.openit.contracts.survey-schema`를 요청 값이 아니라 이 영역이 실제로 쓴(고정한) 값으로 찍는다. 이 영역의 고정은 Dockerfile `ARG BOUNDARY_CONTRACT`·`ARG SURVEY_SCHEMA` 기본값이고 생성 검증기도 그 태그에서 만든다. 요청 버전이 이 고정과 다르면 빌드 전에 이유와 함께 실패한다(라벨이 거짓이 되지 않게). 요청 값은 빌드 인자로 넘기지 않고 `REVISION`만 넘긴다. 이미지에서 읽은 라벨이 고정 값과 같은지도 비교한다.

## 왜
- 요청 값을 그대로 빌드 인자로 넘기면 deploy가 다른 버전을 요청해도 이미지는 고정 태그로 만든 검증기를 담은 채 요청 버전 라벨을 달게 된다(거짓 라벨). 이 영역은 이웃 소스를 설치해 쓰지 않으므로 "실제로 쓴 버전"은 고정 선언이 유일한 근거다.
- 이전 경로(요청 값이 인자로 들어가 라벨이 됨)와 달리 불일치는 조용히 지나가지 않고 실패한다. deploy가 기준표를 올렸는데 이 영역이 아직 안 올렸다면 빌드가 막혀 올릴 일이 드러난다.

## 검토한 대안과 버리는 이유
- 요청 버전을 그대로 쓰고 불일치를 경고만: 라벨이 거짓이 될 수 있다.
- 요청 버전에 맞춰 검증기를 다시 만들어 빌드: 빌드 중 이웃 소스·네트워크에 의존한다(계약 금지).
- StaticImageInterface를 리포 안 문서로 유지: 계약이 없앤 형식을 영역이 따로 정의해 어긋남의 원천이 된다.

## 결과
- 얻는 것: 라벨이 실제와 같다. 계약이 없앤 형식의 사본이 없다.
- 감수하는 것: 기준표 갱신 때 이 영역의 Dockerfile 고정을 먼저(또는 함께) 올려야 빌드된다. 문진 스키마는 주 버전(`1`)만 고정하므로 요청의 같은 주 버전의 다른 부 버전은 통과한다(이 영역은 문진 스키마 패키지를 설치하지 않는다).

## 되돌리는 조건
이웃 소스를 요청의 `dependency_sources`로 받아 실제로 설치·사용하는 구조가 되면 그 경로에서 버전을 읽는다.
